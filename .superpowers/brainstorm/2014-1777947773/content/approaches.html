How should the app be structured?

3 approaches to the overall app flow — pick the one that feels right

A

Tabbed Single Page

Four tabs always visible: Players → Schedule → Scores → Leaderboard. Jump between tabs freely at any time. Simple and familiar — like a spreadsheet with tabs.

Pros

  • Non-linear — jump anywhere
  • Easy to revisit players/scores

Cons

  • Less guided for first-time use
B

Guided Wizard / Stepper

Step-by-step flow: 1. Add Players → 2. Generate Schedule → 3. Enter Scores → 4. View Results. Progress bar at top. "Next" / "Back" buttons.

Pros

  • Clear progression, hard to get lost
  • Great for first-time users

Cons

  • More clicks to go back and fix things
C

Single Scrolling Page

Everything on one long page: player list at top, schedule in middle, live leaderboard at the bottom. Scroll down as the session progresses.

Pros

  • All info visible, no navigation
  • Great on phones/tablets at the court

Cons

  • Can feel long with 12 players + many rounds
