# Internationalization (i18n) — Design Spec

**Date:** 2026-05-18
**Issues:** #13 (About dialog), language support request
**Status:** Approved

## Problem

1. The session chip displays `📅 May 17 · S1` — the "S" prefix is English-specific and cannot be translated.
2. All UI strings are hardcoded in English, blocking non-English-speaking clubs from using the app.
3. There is no About dialog (issue #13) or language selector.

## Decisions

- Use **`ngx-translate`** for runtime language switching (not Angular's build-time `@angular/localize`).
- **Browser/device locale** is detected on startup as the default language.
- User can **override the language** inside the About dialog — preference persisted to `localStorage`.
- **Supported languages at launch:** English (`en`), Vietnamese (`vi`), Chinese Simplified (`zh`), Japanese (`ja`).
- Session chip separator changed from `·` to `|` for better readability with Asian characters: `📅 May 17 | 1` (no "S" prefix in any language).
- The **About dialog** (issue #13) absorbs the language selector — keeps the toolbar clean.

---

## Tech Stack

| Package | Purpose |
|---------|---------|
| `@ngx-translate/core` | Runtime translation service and `translate` pipe |
| `@ngx-translate/http-loader` | Loads JSON translation files from `public/i18n/` |

Translation files are lazy-loaded — only the active language is fetched from the server.

## Translation File Structure

**Location:** `public/i18n/{lang}.json` (e.g., `en.json`, `vi.json`, `zh.json`, `ja.json`)

All strings are flat-ish JSON keyed by component and context. Interpolation uses `{{ key }}` syntax.

```json
{
  "toolbar": {
    "session_chip": "{{ date }} | {{ number }}"
  },
  "players": {
    "title": "Players",
    "add_placeholder": "Enter player name",
    "add_button": "Add",
    "delete_tooltip": "Cannot remove players after the schedule has been generated. Regenerate the schedule first.",
    "roster_locked_snack": "Roster is locked. Regenerate the schedule first."
  },
  "schedule": {
    "title": "Schedule",
    "generate_button": "Generate Schedule",
    "regenerate_button": "Regenerate Schedule",
    "regenerate_confirm_title": "Regenerate Schedule?",
    "regenerate_confirm_message": "All rounds and scores will be cleared. Your player list will be kept."
  },
  "scores": {
    "title": "Scores"
  },
  "leaderboard": {
    "title": "Leaderboard",
    "reset_button": "Reset Session",
    "reset_confirm_title": "Reset Session?",
    "reset_confirm_message": "All players, rounds, and scores will be cleared."
  },
  "session_drawer": {
    "title": "Switch Session",
    "new_session": "+ New Session",
    "delete_confirm_title": "Delete Session {{ number }}?",
    "delete_confirm_message": "All players, rounds, and scores will be permanently removed.",
```

The same structure is replicated in `vi.json`, `zh.json`, and `ja.json` with translated values. The `{{ date }}` and `{{ number }}` interpolation keys are identical across all languages — only the surrounding text (if any) changes.

## `LanguageService` (new)

**File:** `src/app/services/language.service.ts`

Thin wrapper around `TranslateService` that handles detection, persistence, and switching.

```ts
export class LanguageService {
  private readonly STORAGE_KEY = 'pickleball-lang';
  private readonly SUPPORTED = ['en', 'vi', 'zh', 'ja'];
  private readonly DEFAULT = 'en';

  init(): void
  // 1. Check localStorage for persisted preference
  // 2. If none, detect browser locale (navigator.language, e.g. 'vi-VN' → 'vi')
  // 3. Map to supported language, fall back to 'en'
  // 4. Call translateService.use(lang)

  setLanguage(lang: string): void
  // Save lang to localStorage, call translateService.use(lang)

  getCurrentLang(): string
  // Returns translateService.currentLang
}
```

Called once in `App` constructor: `languageService.init()`.

## About Dialog (issue #13)

**File:** `src/app/about-dialog/about-dialog.ts`

A compact `MatDialog` component opened by an ℹ️ icon button in the toolbar. Contains:

- App name and pickleball branding
- Version number — injected via Angular environment token populated from `package.json` at build time
- Credits and GitHub repo link
- **Language selector** — `MatSelect` listing supported languages by their native names:
  - `en` → English
  - `vi` → Tiếng Việt
  - `zh` → 中文
  - `ja` → 日本語

On language change:
1. `languageService.setLanguage(lang)` — saves to localStorage + calls `translateService.use()`
2. UI re-renders immediately via `translate` pipe reactivity — no page reload

## Component Changes

### `app.config.ts`
Register `TranslateModule` with `HttpLoader`:
```ts
TranslateModule.forRoot({
  loader: {
    provide: TranslateLoader,
    useFactory: (http: HttpClient) => new TranslateHttpLoader(http, '/i18n/', '.json'),
    deps: [HttpClient]
  },
  defaultLanguage: 'en'
})
```

### `app.ts`
- Inject `LanguageService`, call `languageService.init()` in constructor
- Inject `MatDialog`, add `openAboutDialog()` method
- Add ℹ️ `mat-icon-button` to toolbar

### `app.html`
- Add ℹ️ toolbar button: `<button mat-icon-button (click)="openAboutDialog()"><mat-icon>info</mat-icon></button>`
- Update session chip: remove hardcoded `S` prefix
  ```html
  📅 {{ selectedDate() | date:'MMM d' }} | {{ selectedSessionNumber() }}
  ```
- Import `TranslateModule` in `App` imports array

### All tab templates
Replace all hardcoded strings with `translate` pipe:
```html
<!-- Before -->
<span>Players</span>
<!-- After -->
<span>{{ 'players.title' | translate }}</span>
```

For dynamic strings in TypeScript (e.g. dialog messages), use `TranslateService.instant()`:
```ts
this.translate.instant('session_drawer.delete_confirm_title', { number: sessionNumber })
```

## Tests

### Unit Tests (`language.service.spec.ts`)
- Browser locale `vi-VN` → resolves to `vi`
- Browser locale `zh-TW` → resolves to `zh`
- Unsupported locale → falls back to `en`
- Persisted `localStorage` value overrides browser locale
- `setLanguage()` updates localStorage and calls `translateService.use()`

### E2E Test Scenarios

| Scenario | Expected |
|----------|----------|
| Browser locale `vi` | App loads in Vietnamese |
| Browser locale `zh` | App loads in Chinese |
| Unsupported locale | App falls back to English |
| Switch to Japanese in About dialog | UI switches immediately, no reload |
| Language persists across page reload | `pickleball-lang` in localStorage applied on next load |
| Session chip format | Shows `May 17 \| 1` — no "S" in any language |
| Session chip in Vietnamese | Shows `17 thg 5 \| 1` (Angular date pipe uses locale) |
